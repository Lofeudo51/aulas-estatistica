# Aulas de Estatística

Material de apoio para aulas de Estatística básica e aplicada.

Conteúdo desenvolvido por André Luiz Morais Lo Feudo para fins educacionais.

## Conteúdos

- Estatística descritiva
- Distribuição normal
- Correlação de Pearson
- Regressão linear
- Intervalo de confiança
- Visualização de dados

## Objetivo

Disponibilizar exemplos, materiais didáticos e páginas HTML interativas para apoio ao ensino de Estatística.

## Desenvolvimento

Os materiais e páginas HTML deste repositório foram desenvolvidos com apoio de ferramentas de inteligência artificial generativa, utilizadas como suporte à programação, estruturação visual e revisão técnica do código.

Todo o conteúdo didático, organização pedagógica, validação conceitual e supervisão final foram realizados pelo autor.
