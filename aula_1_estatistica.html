📐 O que é Regra de Três Diretamente Proporcional?

É uma ferramenta que compara duas grandezas relacionadas. Na diretamente proporcional, quando uma aumenta, a outra também aumenta na mesma proporção — ou quando uma diminui, a outra também diminui.

✏️ Exemplo Resolvido — Regra de Três Direta

"Uma receita usa 3 xícaras de farinha para render 12 pães. Quantas xícaras são necessárias para render 20 pães?"

🎯 Pratique Você Mesmo

"Um pacote de 5 sessões de terapia custa R$ 540. Mantendo o mesmo valor por sessão, quanto custaria um pacote de 3 sessões?"

💡 Dica: mais sessões deveria custar mais ou menos? É direta ou inversa?

Resposta: R$

🔗 Calculando Porcentagem com Regra de Três

Calcular porcentagem nada mais é do que aplicar uma regra de três direta: a base (o total) vale 100%, e você quer descobrir quanto uma parte representa dela. O truque é que a base pode mudar de uma pergunta pra outra — e é isso que vamos ver no exemplo a seguir.

🍽️ Três Formas de Entender a Porcentagem

Um filé mignon de 200g está no prato. Uma fatia de 50g é separada (linha pontilhada), restando 150g no prato.

Repare que as três perguntas abaixo usam o percentual de um jeito diferente — a "base" (o que vale 100%) muda em cada uma.

1) A fatia de 50g (pontilhada, apontada pela seta) representa quantos % do bife inteiro (200g)? %

2) O bife inteiro (200g) representa quantos % da fatia de 50g (pontilhada)? %

3) O pedaço que restou (150g) tem quantos % A MAIS de peso do que a fatia separada (50g)? (ou seja: a diferença entre os dois, 100g, em relação à fatia separada) %

🔎 Tipos de Variável

Antes de organizar os dados em tabela, é importante saber que tipo de variável está sendo coletada.

Tipos de Variável

Representa uma categoria ou qualidade, não um número.

Nominal: sem ordem. Ex.: cor dos olhos, gênero.

Ordinal: com ordem. Ex.: satisfação (ruim/regular/bom).

Representa uma quantidade numérica.

Discreta: valores contáveis. Ex.: número de filhos.

Contínua: qualquer valor no intervalo. Ex.: altura, peso.

📋 Dados Brutos

Dados brutos são os dados exatamente como foram coletados, sem nenhuma organização.

  • Notas anotadas na ordem da chamada
  • Respostas de um formulário, na ordem de chegada
  • Medições feitas ao longo do dia

📈 Rol

Rol são os mesmos dados, organizados em ordem (crescente ou decrescente).

  • Facilita ver o menor e o maior valor
  • Ajuda a perceber repetições
  • É o passo antes de qualquer tabela

Exemplo:

Observação por norma, uma tabela estatística não tem LINHAS VERTICAIS fechando os lados ou separando colunas — só linhas horizontais.

Veremos agora um tipo de tabela especial, chamada Tabela de Frequências Sem Classe. Ela é muito utilizada quando temos muitos dados que se repetem — em vez de listar valor por valor, mostramos quantas vezes cada um apareceu.

🔢 Frequência Absoluta (fi)

Quantas vezes cada valor aparece nos dados.

📊 Frequência Relativa (fri)

Use regra de três para calcular quantos % cada fi representa do total.

📈 Frequência Acumulada (fa)

Para cada fi se calcula sua respectiva fa, somando-se todas as fi's anteriores.

🔢 Veja na Prática!

Clique no botão acima
Total 100% — 100%

📐 Fórmulas

n = Σfi  →  a soma de todas as frequências absolutas é igual ao tamanho da amostra. No exemplo acima: n = 15.

fri = (fi / n) × 100  →  aqui já mostramos a frequência relativa direto em forma de percentual.

fa = soma das frequências absolutas até aquele valor (frequência acumulada).

fra = soma das fri's até aquele valor (frequência relativa acumulada, em %).

Até agora, cada tabela organizou uma variável (nota, tempo de atendimento...). Mas às vezes queremos cruzar duas variáveis ao mesmo tempo — para isso usamos a Tabela de Dupla Entrada.

🗂️ Elementos de uma Tabela de Dupla Entrada

Linha uma das variáveis, organizada nas linhas.

Coluna a outra variável, organizada nas colunas.

Célula o cruzamento entre uma linha e uma coluna.

Totais Marginais a soma de cada linha e de cada coluna, individualmente — aparecem nas margens (bordas) da tabela.

Total Geral a soma de todos os totais de linha (ou de coluna) — sempre dá o mesmo valor.

Uma Série Estatística é uma tabela com duas variáveis: uma delas é sempre o tempo ou local (região) ou a categoria; a outra é a variável medida, que sempre varia. O tipo de série depende de qual dessas três variáveis (tempo, local ou categoria) muda.

🗂️ Os 3 Tipos de Série

Temporal o que varia é o tempo (local e categoria fixos). Ex.: vendas de uma loja, ano a ano.

Geográfica o que varia é o local (tempo e categoria fixos). Ex.: população por região, no mesmo ano.

Específica o que varia é a categoria (tempo e local fixos). Ex.: matrículas por curso, na mesma faculdade e ano.

🧩 Elementos de um Gráfico

Independente do tipo (barras, pizza, histograma, linhas...), todo gráfico estatístico deve ter:

Título do Gráfico diz o que o gráfico representa como um todo.

Título do Eixo X identifica a variável ou categoria representada horizontalmente.

Título do Eixo Y identifica a variável representada verticalmente (geralmente a frequência ou o valor medido).

Legenda explica o que cada cor/símbolo representa — necessária quando há mais de uma série de dados no mesmo gráfico.

Fonte indica de onde vieram os dados — assim como nas tabelas.

Observação os rótulos de dados (o valor escrito em cima de cada barra/ponto) são opcionais.
